Company: Capgemini
Position: Full-Stack QA Engineer (SDET)

Capgemini is seeking a highly skilled Full-Stack QA Engineer (Software Development Engineer in Test) to join our engineering team. In this role, you will bridge development and quality assurance by designing robust automated testing frameworks across our full technical stack.

Key Responsibilities
Design and maintain scalable automation frameworks for frontend, backend microservices, and databases.
Build E2E, API automation, and unit tests using modern frameworks.
Integrate automated tests into CI/CD pipelines for continuous quality gates.
Execute performance testing on REST/GraphQL services and identify bottlenecks.
Collaborate with developers, product managers, and DevOps in Agile/TDD workflows.
Debug complex async systems and provide clear technical post-mortems.
Technical Requirements
Backend/API: Java (Spring Boot), Node.js (Express), or Python (FastAPI); strong REST/microservices knowledge; Postman/RestAssured/Supertest; SQL/NoSQL validation.
Frontend: Angular/React/Vue.js; Cypress/Playwright/Selenium; strong DOM/CSS/async UI behavior handling.
DevOps: Docker, cloud familiarity (AWS EC2/S3), CI/CD tools (GitLab CI/CD, GitHub Actions, Jenkins).
Soft Skills & Qualifications
Strong debugging and root-cause analysis mindset.
Agile/Scrum proficiency (planning, refinement, execution).
Clear communication with technical and non-technical stakeholders.
Bachelor’s in CS/Software Engineering (or equivalent experience).
Proven experience in automation-heavy QA or full-stack engineering roles.
